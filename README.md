# goalie

[![Deploy to S3](https://github.com/andrewmacheret/goalie/actions/workflows/deploy.yml/badge.svg)](https://github.com/andrewmacheret/goalie/actions/workflows/deploy.yml) [![Canary](https://github.com/andrewmacheret/goalie/actions/workflows/canary.yml/badge.svg)](https://github.com/andrewmacheret/goalie/actions/workflows/canary.yml) [![License](https://img.shields.io/badge/license-MIT-lightgray.svg)](https://github.com/andrewmacheret/goalie/blob/master/LICENSE.md)

A daily goal tracker that reads and writes a Google Sheet with the Sheets API.

See it running at [https://andrewmacheret.com/projects/goalie](https://andrewmacheret.com/projects/goalie).

Goalie and [Miler Lite](https://github.com/andrewmacheret/miler-lite) sign in with Google as one app, [Daily Tracking - Goalie and Miler Lite](https://andrewmacheret.com/projects/goalie/about.html) (`www/about.html`). They share this [privacy policy](https://andrewmacheret.com/projects/goalie/privacy.html) and these [terms of service](https://andrewmacheret.com/projects/goalie/terms.html), from `www/privacy.html` and `www/terms.html`.
